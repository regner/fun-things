## Independent dry run

The [raw fixture](fixtures/p0-06.md) contains a fictional contract, three GDScript
files and their two scene files plus project settings. It is stored as Markdown so
deliberately flawed samples cannot become imported game code. The exact fenced files
were extracted into `/tmp/p0-06-review-_q00d5rw` for the evaluation.

A fresh subagent received only the skill path, temporary fixture path, canonical
guidance and a read-only review request. It received no intended answers, suspected
bugs or proposed fixes, and was instructed not to read repository evaluation records
or use the live editor. The request required severity, fixture-relative line locations,
evidence/impact, minimal fixes, independent regression cases and validation limits.

The [unaltered independent review](p0-06-dry-run.md) reported eight findings:

| Severity | Location in extracted fixture | Finding |
| --- | --- | --- |
| P1 | `match.gd:19–31` | RPCs trust claimed identity and client-selected damage |
| P1 | `actor.gd:44–54` | Prediction/replay repeats authoritative outcomes and effects |
| P1 | `match.gd:28–31`, `actor.gd:30–40` | Command batches, queues and tick work have no bounds |
| P2 | `actor.gd:23–26`, `hud.gd:14–15` | Respawn observers read state before restoration |
| P2 | `actor.gd:23–40` | Queued firing survives into the next life |
| P2 | `actor.gd:18–19`, `match.gd:10–14` | Replica tree entry invokes authoritative respawn |
| P2 | `actor.gd:9`, `actor.tscn:7` | Export rename loses authored tuning |
| P3 | `actor.gd:35` | Callback placement violates pinned member order |

Each finding includes evidence, impact, a minimal fix and an independent regression
case. The reviewer separated static inference from execution and noted the main
scene does not exercise the reviewed APIs. It did not mistake missing planned
tooling or a Mise state-directory warning for gameplay defects. No skill revision
was warranted by this evaluation.

Reviewer checks: raw source/caller/scene and canonical-guidance inspection, local
dependency-path checks, manual style review, gdstyle 0.3.0 lint and installed Godot
version verification (`4.8.dev7.official.c971f93e7`). Lint returned exit 0 with the
reported member-order warning. The reviewer did not run compilation, import,
gameplay, editor roundtrips or network checks; it reported those limits explicitly.

P0-06's acceptance criteria are met: valid frontmatter/links, meaningful findings
from an independent isolated dry run and explicit missing-check reporting. This
closed the review-skill task while P0-02/P0-03 and gameplay proofs remained open.

After rebasing onto `main`, the P0-02 contract drafts are present and available to the
skill's existing conditional reads. The absent-contract observations in the original
dry run describe that evaluation's inputs; P0-03 checks and gameplay proofs remain
future work. The branch preserves all completed foundation tasks in TODO.md.

## Follow-up — Godot conventions

On 7 October 2026 the user clarified that the review should explicitly cover scene
files for all authored UI/2D/3D composition and "call down, signal up", plus other
Godot conventions. The original skill covered saved placement and ownership but did
not make those two rules explicit.

The [canonical conventions](../development.md#godot-scene-and-script-conventions)
now define saved composition, reusable scene APIs and dependency direction, typed
injection, lifetime/transform parentage, Resources, physics/input callbacks and UI
layout/focus. AGENTS.md summarizes the two requested rules. Three added review lenses
check scene composition, communication and engine usage against that guidance.
Runtime instantiation of saved scenes and pure logic/data scripts remain valid.

The guidance was checked against the official Godot sources linked in development.
Frontmatter, local links/anchors and diff whitespace passed validation. The original
independent dry run above is retained unchanged; no additional behavioral dry run,
editor operation or gameplay/network test was performed for this documentation update.
