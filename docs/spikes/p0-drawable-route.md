Wayland and Xwayland connections answer read-only metadata queries, but that does
not establish a usable private window, scanout, input, focus or target-device route.
No engine/editor/window/input/configuration operation ran in this discovery.

Dummy audio and real-time physics. This changes the requested presentation mode;
it is absent from both consumed S05 invocations. It is **optional/low-confidence,
not a demonstrated drawability, throttling or suspension fix**.

**Critical qualifier:** fresh `wayland-info` advertises `wp_fifo_manager_v1`.
At the exact pinned source, `WaylandThread::is_fifo_available()` checks that
registry name. Vulkan manual VSync emulation requires FIFO to be **unavailable**.
Thus the emulator timeout branch may already have been inactive on this compositor.
Do not sell disabling VSync as bypassing the failed branch, infer the old runtime's
suspend reason, or promise a pass. Actual `VSYNC_DISABLED` is necessary to credit
this changed condition; it is not sufficient for any image/native criterion.

Recommended ordering: ROOT evaluates the finite card below; either commission
exactly that conditional image collection or decline its weak causal justification
and preserve STOP. No automatic fallback experiment. Continue independent P0 work
in either case. A real interactive surface and later hardware proofs remain separate
missing resources, not requests to repeatedly probe or repair the shared desktop.
