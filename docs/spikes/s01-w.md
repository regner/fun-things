## Question and result

Can the committed Linux-authored S01 GLBs be reproduced byte-for-byte by the specified
Windows Blender 5.2 installation?

**Yes.** `prototypes/s01/tools/s01/reexport.py` exported both committed sources to temporary GLBs with
`C:/Program Files/Blender Foundation/Blender 5.2/blender.exe`. The tool's existing
structural checks passed, then its byte comparisons passed for both outputs:

| Asset | Committed and Windows scratch GLB SHA-256 | Result |
| --- | --- | --- |
| `s01_static` | `80ba398233ce9ffe2fc2e8d505fe9bf720496991c230ca479d5cba153733c37a` | byte-identical |
| `s01_rig` | `7bfd60aeeff70c8b38e28c2e6ccb57c1b79ebfdbc29ba0ea9064bbdf6f6fab44` | byte-identical |

The source hashes also match the accepted S01 receipt: `s01_static.blend` is
`b4b438c4407707fe3dcb25fea1e1b9050af2feb2c27f0539ab4422981ba38af4` and
`s01_rig.blend` is
`c84a6cb9705f37c5d9122e618feee1febb8ae7ab808c861aafbba8f56b6a5a92`.
No semantic fallback was needed because the stronger byte-identity criterion passed.

## Exact Windows toolchain

`blender.exe --version` reported Blender **5.2.2 LTS**, Windows Release, build hash
`d13f752e3b9c`, built 2026-09-15 01:37:04 from branch `blender-v5.2-release`. Both
export logs report bundled glTF exporter **5.2.40**. This is the same Blender version,
build hash, and exporter version recorded by S01 on Linux; the platform build date
differs. The Windows exporter found optional Draco and MeshOptimizer libraries, but
compression remained disabled and the existing validator confirmed no GLB extensions.

The observed cross-platform result supports retaining the existing Blender 5.2.2 LTS
version assertion and byte comparison. It does not justify a looser semantic comparator
or a platform-specific output pin. Future Blender patch, exporter, settings, or source
changes still require a fresh re-export check on each supported authoring platform.

  timeout 180 python prototypes/s01/tools/s01/reexport.py \
  --logs C:/tmp/ft/lanes/s01-w/reexport

The command printed `PASS both sources exported; byte-identical`. The external runner
output remains under `C:/tmp/ft/lanes/s01-w/reexport/`. Review evidence is retained in
[`s01-w-evidence`](s01-w-evidence/): exact version output, both complete Blender export
