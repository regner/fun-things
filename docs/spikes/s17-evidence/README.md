# S17 evidence catalogue

Canonical contended protocol-compliant run: `result.json`, with complete 3,600-tick warmup
receipts and 36,000 measured tick samples in `seed-171.json`, `seed-272.json`, and
`seed-373.json`. Each seed has eight measured chains, for 24 total. Every seed receipt also
binds S10's continuous owner ticks: warmup ends at -1, measurement spans 0..35,999, and only
owner ticks 35,700..35,999 suppress new car-contact deaths. The matching `.log` and
`.engine.log` files contain process output; `import*.log` retain the isolated-project import.
`SHA256SUMS.txt` binds every retained raw file.

The run used pinned Godot `4.8.dev7.official.c971f93e7` on an Intel Core Ultra 7 165H host
running Windows 11 Enterprise 10.0.26200 build 26200. Each headless repetition observed
other Godot processes before launch or during startup/warmup and is labelled a **contended
upper bound**. No contention subprocess ran during a measured window. Machine, OS, Godot,
headless display and renderer identity are retained in `result.json` and every seed receipt.

The source checkout was edited directly because the editor was unavailable; the minimal
saved scene was imported with the pinned engine, and script UID sidecars were generated by
that import. All Godot invocations in the runner are wrapped in GNU `timeout`, with an
additional Python child deadline.

Reproduce from the repository root with a fresh output directory:

```sh
export PATH="$(dirname "$(mise -C C:/GameDev/git/fun-things which godot)"):$(dirname "$(mise -C C:/GameDev/git/fun-things which gdstyle)"):$PATH"
timeout 5000 python tools/s17/run.py --godot "$(command -v godot)" \
  --output C:/tmp/ft/lanes/s17-host-tick/reproduction
```
