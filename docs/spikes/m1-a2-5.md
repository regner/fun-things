# M1-A2.5 player presentation and local camera

10 October 2026. This production row connects the existing standalone session path to the saved
Brackett Match and the delivered Coral Courier. Production code does not load the archived spike
fixtures.

## Implemented boundary

- Boot listens for the existing `standalone_started` completion, instances the saved Match and player,
  places `LocalPlayer` at provisional `Spawn01`, and binds the one saved `LocalRig`. Boot remains the
  process-lifetime coordinator; Match owns the runtime actor and rig lifetime.
- `LocalRig` samples `DesktopFootInput` once per fixed physics tick and calls the shared
  `ActorMotion.step` authority path. Its authored perspective camera is 47 m above the controlled body,
  points vertically down with fixed north-up orientation, and keeps the selected 42 degree FOV. Mouse
  aim therefore continues to use the camera ray against the actor ground plane.
- Coral Courier locomotion is selected from solved velocity relative to facing. The prefab measures
  each clip's authored foot-contact travel and stance time, then `play_layered` scales lower-body
  playback to the solved speed. Idle is layered with the default pistol hold and death uses the
  delivered retained full-body clip. Presentation writes neither pose nor velocity.
- `ActorMotion` applies default gravity with a 0.25 m floor snap and 45-degree maximum floor angle in
  the unchanged standalone, authority, and replay steps. The capsule follows bridge and ramp grades
  in either direction and falls rather than floating after leaving a ledge.
- Escape emits local leave intent. Boot neutralizes and unbinds input, queues the complete Match for
  removal, leaves the standalone session, and restores the authored main menu after cleanup.

The delivered 0.8-second run contacts travel about 0.52 m forward/back and 0.312 m laterally. Matching
5 m/s therefore produces approximately 3.85x forward/back and 6.41x lateral playback. No runtime cap
hides that source limitation, so cadence is visibly too fast even though average stance slip is
removed. An art follow-up will re-author the Coral Courier run and strafe clips with a 5 m/s stride;
this lane intentionally does not re-author approved animation assets.

The Godot editor and MCP scene tools were unavailable to this worktree. The explicitly requested
`local_rig.tscn` hierarchy and Match node additions were authored as text, imported with the pinned
engine, and the new scene was load/pack/saved headlessly. Script UID sidecars are committed.

## Owner play-test note

From the repository root, use the pinned engine and a 60 FPS cap:

```sh
export PATH="$(dirname "$(mise which godot)"):$PATH"
godot --path . --max-fps 60
```

Choose **Play solo**. WASD walks in fixed world/screen directions, the mouse aims the Courier on the
street plane, and Escape returns to Boot. Review the Courier while changing movement direction without
changing facing, confirm the camera remains north-up and centred, then walk east/west along Signal Row
and into the adjoining junction. Look for directional foot sliding, wall/kerb snags, roof occlusion,
and any menu or held-input residue after leaving and starting again. Fire/alternate intent is carried
but intentionally has no combat outcome in this row; networking is not part of this first playable.
