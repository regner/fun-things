## Ownership and outcome validation

This ownership description is historical: `building_view.gd` was removed with the
cutaway, and `motion_rules.gd` now owns the pure world-relative velocity/yaw rule.
Input collection, `actor_motion.gd`, aim query, camera and probe overlay remain
separate. See [the current controls record](s02-controls.md) for current behavior.
Saved scenes still own composition, UI, collision and placement; runtime code moves
only dynamic actor/camera state. The 2D marker/trace remains a diagnostic overlay,
not a generated 3D mesh.

`prototypes/s02/tools/s02/run.py` copies the saved project into an isolated profile, removes only
development autoload/editor plugins in that copy, imports fresh, checks actual
production APIs and compares persisted resource hashes. It checks forward/reverse
distance, turn-without-strafe, facing-relative movement, wall stop, passage/corner
traversal, clear hit, blocked hit, close-wall muzzle obstruction, bounded firing,
nonfinite intent, routed physical-key mapping, cancellation, overlapping keyboard aliases in both orders, lifecycle-safe cadence,
free-space target overlap queries, blocked-to-clear walking/aiming, camera axes, source
sockets, building heights, source links and UID/path agreement. Runtime logs and
exit status both matter. This is not a network, packaged export or full-plugin proof.

Observed wall stop: (6,0.001,0.38021); corner traversal ends approximately
(3,0.001,-9). Forward travels5 m in one second; reverse3 m. An independent live MCP
physical-W trial moved1.25 m in250 ms; this is submitted-input behavior, not a human
latency/feel measurement. Query hit the clear target and world blocked the hidden
one. Re-running after the cutaway preserved collision/query outcomes.

Input API checks pass for focus cancellation, no held echo on regain and local-menu
cancellation, including overlapping aliases and preservation of firing cadence.
**Current native OS focus revalidation is incomplete.** The post-fix
[standalone run](s02-evidence/os-focus.log) and
[post-capture run](s02-evidence/history/post-capture-focus-failure.log) both started
minimized yet reported native focus; minimize/restore produced no focus-loss signal.
The runner correctly failed; these are not clean passes or evidence that real
focus loss was handled on this revision. No repeated retries or weakened assertions

Before the fixes, both producer and independent art reviewer observed real
