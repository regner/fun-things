# S05 evidence catalogue

This is the one bounded S05 experiment, with original protocols retained before
measurement. `retention.json` binds each raw artifact's bytes/SHA256 and stored
bytes/SHA256; `.gz` files decompress losslessly (deterministic gzip, mtime zero).
No credential files, tokens, private user directories or staged addon copies are
retained. The JSON request artifacts contain authored source/tool arguments only.

- `editor/protocol-before-measurement.md`, `protocol-amended-before-measurement.md`
  and `protocol-queue-before-measurement.md`: original, single-root grid and finite
  reservation-pressure criteria. The last timestamp receipt precedes its run.
- `canonical/`: seven-script pinned compilation/style, both public API rows and
  real three-process ENet rows. `result.json` binds commands, PIDs, literal outcomes,
  source hashes and unchanged staged sources. This run predates the added queue
  branch in `proof.gd`; damage/life/replication APIs are unchanged.
- `queue-pressure/`: failed added check, with raw stdout/engine/compiler logs.
  `queue-corrected/`: corrected owner-tick synchronization, same saved burst;
  seven-script compilation/style and finite capacity result/source fingerprints.
- `all-owned-checks/`: all48 owned affected dependency/S05 scripts compiled explicitly
  and pinned formatting/lint. The subsequent proof-only amendment is compiled in
  the queue runs.
- `negative-retirement/`: isolated public-API counterexample removes only retired
  ShotId rejection; active duplicate checks remain. Expected negative failed at
  `retired ShotId rejected`. Candidate files were untouched.
- `initial-host-pass/`: historical run before the lifetime admission guard.
  `failed-sandbox-import/`: socket creation denied before gameplay, kept separately.
- `editor/`: actual HOST inventory, saved main state, graceful exit/absence,
  single pinned worktree editor, installed-handler authoring/refresh/roundtrips,
  saved IDs/linked ancestry and original resource fingerprints. Early class-index
  and placement failures remain raw. Boundary resources preserve501 original files.
- `raw-s05-todo.md`: full original S05 task acceptance, before partial status edits.

Reproduce in a fresh external directory with the exact pinned executables:

```sh
python tools/run_s05.py --godot /path/to/4.8-dev7/godot --gdstyle /path/to/0.3.0/gdstyle --output /tmp/s05-new
python tools/s05/check_resources.py --base c8096b55ef97412552366fdaa74c220b976ed82e --output /tmp/s05-resources.json
```

Use `--queue-only` for the affected finite pressure row. This is Linux loopback
technical evidence, no drawn VFX, input/feel, device or Steam acceptance. The
contract supplement and spike record describe provisional policies/open gates.
