# Terrace Ward asset breakdown

Detailed set from the liked [Terrace Ward concept](03-terrace-ward-v02.png) and the
owner's requirement for modular apartments. The [central registry](asset-register.md#03-terrace-ward-assets)
owns needed district uses, candidates, briefs and next actions. This breakdown
explains the set; quantities are reusable designs/sets, not placed instances.

## Apartment kit: seven module records

| Module | Brief member | Coverage |
| --- | --- | --- |
| Straight one-storey bay | [Apartment kit](../../assets/d03_apartment_family.md), `.05` | Repeatable wall/window section; vary run length and storey count |
| Inside/outside corner set | Same brief, `.06` | Compatible turns for L/U groups and recessed courts |
| Finished end / exposed wall closure | Same brief, `.07` | Complete short blocks and open ends without custom whole-building meshes |
| Ground-floor entrance bay | Same brief, `.08` | Door, entrance surround and exterior stair-core expression |
| Balcony / loggia frontage insert | Same brief, `.09` | Repeated recessed/projecting frontage treatment and its railing |
| Roof-cap set | Same brief, `.10` | Straight/end/corner pieces matching the liked low-pitched and stepped roof forms |
| Height-step closure | Same brief, `.11` | Exposed upper-storey walls and roof junctions where neighbouring heights differ |

The four earlier building records `.01–.04` are **assembly references** for L,
open U, short infill and stepped-bar compositions made from that same kit. They
are not four additional one-off building models. Normal window frames, doors,
facade trim, balcony rails and roof edges stay with their modules; shared material
variants provide blue-grey, teal and coral without new geometry for each colour.

The large southern landmark is a composition of these parts around open ground,
not another bespoke apartment building. Common dimensions, roof/corner joins and
height transitions still need a module concept sheet before any production.

fascia artwork stays a candidate: the current overview does not clearly select a
separate shop or commercial frontage. No swing set, slide, hoop, fountain or statue
is added from ambiguous image detail.

## Shared structures, props and finishes

| Required design | Brief and members |
| --- | --- |
| Boardwalk straight/bend deck, fascia, supports and landward transition | [Boardwalk](../../assets/city_boardwalk.md), `.01–.05`; same kit already needed in Northpoint and The Crescents |
| Seaward boardwalk rail | [Quay furniture](../../assets/city_quay_furniture.md), `.02`; separate from apartment balcony rails |
| Low seawall and rock shore | [Shore edges](../../assets/city_shore_edges.md), `.01`, `.03` |
| Street pole, short pedestrian fixture and wall light | [City lights](../../assets/city_lights.md), `.01`, `.02`, `.04` |
| Straight bench | [City seating](../../assets/city_seating.md), `.01`; courts and occasional boardwalk seating |
| Rectangular and round planter | [Planting](../../assets/city_planting.md), `.01–.02`; reuse rather than unique containers for each court |
| Low shrubs and broad-canopy tree | Same brief, `.03–.04`; simplify the image's dense planting |
| Quiet paving, grass and planted soil | [Ground finishes](../../assets/city_ground_finishes.md), `.01`, `.04–.05`; site-specific outlines use shared appearances |

Raised planter edges belong to their containers. Ordinary ground beds use shared
soil/planting, without treating every bed as a new prop. Keep courtyard openings,
side walking links and the coastal route clear. The boardwalk extends beyond both
district boundaries; the full island circuit still needs later district fit review.
Road surfaces remain excluded and are reserved for future automatic tooling.

were created, and the current image does not validate modular joins or clearances.

Open-sea appearance uses the shared `city_water_look.01` visual study.
The central registry records these uses without new district-specific geometry.
