# Communication cards

Fill only relevant fields with readable sentences. Link shared contracts at an exact
revision and the complete raw requirements/grants; do not replace them with summaries.

## Task

```text
Implement [outcome] directly in [workspace/path/branch], base [exact revision].
Owner and scope: [lead, owned paths/resources, exclusions].
Inputs: [raw requirements/grants, accepted prerequisite evidence, role contract revision].
Done: [observable acceptance and phase-specific checks; remaining external gates].
Recovery: [total effort/time cap and total attempts across phases; preservation duties,
recoverable owned mistakes and escalation triggers; phase acceptance boundaries].
Launch receipt: [discovery locator/time, settings, parent ID and notification route].
Review/delivery: one clean-context reviewer, exact final HEAD/base, shared evidence
contract, saved clean/quiescent handoff. Integration belongs to ROOT.
```

## Review

```text
Independently review [task], clean context, exact [candidate] on [base].
Read [complete raw requirements/grants, immutable contracts and artifact index].
Scope/checks: [paths, acceptance, remaining gates, allowed resources and effort cap].
Return full findings/check evidence and exact revision disposition under reviewer contract.
```

## Follow-up

```text
Changed fact: [new base, input, finding or authority; exact locator].
Consequence/action: [bounded next action, owner, acceptance/budget changes].
Preserve [relevant work/gates]. Notify [parent route] at [completion or real blocker].
```

## Status

```text
Delivered [result]. Running [actual action].
Blocked [work] by [actual missing authority/input/resource or slot conflict, owner].
Next trigger: [release/input/completion]. Remaining acceptance: [unproved gates].
```

Omit empty blockers. Do not repeatedly report unchanged waiting; start ready authorized
work and use completion notifications. An approval rejection is a real blocker with
its stated reason, not permission to route around it.

## Handoff

```text
Workspace/branch; exact HEAD/base; scope and TODO outcome.
Reviewer identity/model/effort; exact reviewed revision/disposition and report locator.
Checks/results/diagnostics/limits; fixes and remaining gates.
Evidence index; complete expected-set/hash/readback result and immutable references.
Git clean; work saved; owned writers/handles quiescent; integration owner/next action.
```
